# The Excuse That Almost Works — GTA 6 Launch Week

Entry for [The Excuse That Almost Works](https://make.fun/c/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5) on make.fun.

`main.py` writes one line to `/output/entry.txt`: the text a gamer sends
the boss to skip work on GTA 6 launch week. One line, plain words, no
setup, no explanation, no signature — a hurried text built on a specific,
boring, almost-believable detail (an overheated console, a room smelling
of burnt plastic, waiting on support) whose laugh comes from its own
logic: the console died doing the one thing he wanted — the GTA 6 preload.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: no network, no randomness, no external input. The output
is byte-identical on every run.
